# Changelog

## 2.16.0 — Chat / Admin / OnePass

- Исправлен стабильный viewport чата при большом количестве сообщений: отдельный вертикальный scroll-контейнер без скачков страницы.
- Фото, видео и голосовые до 20 МБ передаются отдельными зашифрованными чанками; крупные payload больше не пишутся одной строкой в D1.
- Добавлены CORS-заголовки для ответов Worker даже при внутренних ошибках.
- Табличный редактор заметок перестал добавлять строки рекурсивно при каждом вводе; операции строк/столбцов выполняются без повторной нормализации DOM.
- «Друзья» возвращены в мобильную навигацию; выбор пользователя открывает отдельную страницу чата с этим пользователем.
- Админка вынесена в отдельный раздел и расширена карточкой пользователя, статистикой, отзывом входов и удалением профиля.
- OnePass поддерживает несколько устройств, отображает сохранённые варианты и позволяет удалить любой отдельный passkey или все сразу. При регистрации сохраняется определение устройства.
