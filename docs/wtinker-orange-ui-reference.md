The 7.6.0 interface is rebuilt against this reference. The implementation keeps the product's existing behavior and route structure while replacing the visual system.

## Core tokens

- Primary orange: #F97316
- Dark orange: #C2410C
- Light orange: #FFF4E8
- Light surface: #FFFFFF
- Light canvas: #F7F5F2
- Dark canvas: #151311
- Dark surface: #1C1916
- Text: #211D19 / #F4EFE9
- Border: #DDD7D0 / #3A332D
- Default radius: 10–12px
- Controls: 40–42px
- Grid: 8px rhythm
- Icon stroke: 2px

## Product rules

No gradients, emoji UI, decorative blobs, glassmorphism, neon effects, fake depth, or duplicated legacy layers. Components use the same border, radius, control, typography, spacing, state, and responsive rules across social, work, chat, profile, settings, notifications, communities, channels, admin, authentication, and setup screens.

The Visual Playwright suite remains the acceptance gate for desktop/mobile and light/dark states.
