# WTinker 7.0.0 — Screen Contract

## Home
Primary question: What matters to me today?
- next shift
- pay/balance
- absence
- short social context
- quick actions

## Social
Primary question: What is happening in my work network?
- composer
- feed
- reactions/comments
- mentions
- saved posts
- loading/empty/error/retry

## People
Primary question: Who am I looking for?
- WTinkID
- username
- name/company/position
- relationship state
- profile preview
- friend request

## Communities
Primary question: Where do these people work together?
- directory
- detail
- feed
- members
- events
- membership/admin state

## Chats
Primary question: Who do I need to talk to?
- personal
- groups
- corporate
- E2E status
- search
- messages
- replies/reactions
- attachments/voice
- read state

## Work
Primary question: What is my working state?
- calendar
- shifts
- payroll
- taxes/advances/balance
- absence
- notes
- teams/events/swaps

## Notifications
Primary question: What changed?
- unified timeline
- unread state
- category context
- deep link
- mark read/all

## Profile
Primary question: Who am I here?
- identity
- username/WTinkID
- work identity
- publications/communities/friends
- sessions/security
- OnePass/WebAuthn

## Responsive rules
- minimum 44px touch target
- no horizontal page overflow
- full-screen chat on narrow devices
- keyboard-safe composer
- safe-area padding
- accessible focus order
- reduced motion
