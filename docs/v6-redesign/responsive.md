# v6 Responsive Rules

## Breakpoints
- <= 767px: mobile composition
- 768–1050px: compact/tablet shell
- > 1050px: full desktop shell

## Mobile
- Hide desktop sidebar.
- Use bottom navigation.
- Sticky topbar.
- Single-column content.
- Full-width primary actions.
- Sheets replace large desktop modals.
- Chats use full-screen conversation view.
- Personal/Groups/Channels remain discoverable through a 3-option mode switcher.
- Tables become horizontally scrollable rather than squeezed.
- Inputs and buttons maintain 44px+ touch targets.

## Tablet
- Compact sidebar can collapse to icon rail.
- Two-column layouts collapse selectively.
- Right contextual rail is hidden.

## Desktop
- 248–264px sidebar.
- Main area fluid up to 1440px.
- Contextual right rail only where it adds information.
- Chat split view remains available.

## Accessibility
- Visible keyboard focus.
- Semantic buttons instead of clickable divs.
- ARIA pressed/expanded where applicable.
- Contrast-safe text.
- Reduced motion.
- No information conveyed by color alone.
