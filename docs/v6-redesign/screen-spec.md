# v6 Screen Specification

## 01 Home
Purpose: one glance at personal work and social activity.
- Greeting + presence
- Today / next shift
- Balance/pay snapshot
- Upcoming events
- Recent social activity
- Quick actions
- Empty state for first-time users
- Permission-aware work widgets

## 02 Social
Purpose: primary public work-social experience.
- Composer
- Feed tabs: For you / Following / Communities
- Publication card
- Reactions/comments/share
- Mention autocomplete
- Attachment/media preview
- Pinned/highlighted posts
- Infinite/paginated feed states
- Loading skeleton, empty and retry states

## 03 People
Purpose: discovery and relationships.
- Search by WTinkID OR username
- Filters
- People cards
- Relationship state
- Profile preview
- Friend request action
- Public profile deep links
- Authenticated “Отправить заявку” when valid

## 04 Communities
Purpose: groups around work, interests and teams.
- Directory
- Community card
- Detail header
- Feed
- Members
- Events
- Admin controls according to permissions
- Join/leave/request state

## 05 Chats
Purpose: one communication surface for all chat types.
- Personal
- Groups
- Corporate channels
- Search
- Pinned messages
- Reactions
- Replies
- Voice
- Attachments
- Read state
- E2E/security indicators
- Mobile mode switcher remains visible

## 06 Work
Purpose: existing Work OS in the new shell.
- Schedule/calendar
- Shifts
- Payroll
- Tax
- Advances
- Balance
- Leave/vacation/sick leave
- Notes
- Documents
- Teams
- Events
- Shift swaps
- Directory integrations
- Dense tables remain readable; no decorative redesign at the cost of precision

## 07 Notifications
Purpose: unified activity center.
- Internal notifications
- Social activity
- Friend requests
- Mentions
- Chat activity
- Work events
- Read/unread grouping
- Deep links
- Mark read/all
- Empty and offline states

## 08 Profile
Purpose: identity + personal workspace.
- Avatar/cover
- Name, username, WTinkID
- Bio
- Work identity
- Publications
- Communities
- Friends
- Security
- Sessions
- OnePass/WebAuthn/passkeys
- Settings

## 09 Mobile System
- Bottom navigation
- Contextual sheets
- Full-screen chat
- Responsive cards
- Keyboard-safe composer
- Safe-area support
- 44px minimum targets
- Landscape handling
