# WorkerTink Roadmap

> Roadmap от текущей версии **3.0.0** до **7.0.0**.  
> Версии описывают продуктовые этапы, а не только технические релизы. Конкретный состав minor/patch-релизов может меняться без изменения целей соответствующего major-релиза.

---

## v3.0.0 — Foundation / текущая база

**Статус: текущая версия**

WorkerTink уже включает базовый Work OS и социальный слой:

- рабочая социальная сеть, публикации, сообщества и события;
- поиск людей по имени, должности, WTinkID и username;
- публичные профили;
- личные и групповые E2E-чаты;
- корпоративные каналы и роли;
- read state, ответы, редактирование и удаление сообщений;
- голосовые сообщения;
- фото, видео и файлы;
- графики смен и расчёт зарплаты;
- отпуск, больничные и рабочие заметки;
- команды, документы и рабочие ссылки;
- PWA, offline shell и push;
- Desktop для Windows/macOS/Linux;
- центр уведомлений;
- обязательное обновление клиента через PWA/Service Worker.

### Цель этапа

Стабильная production-база, на которой можно строить следующие версии без постоянных крупных архитектурных переделок.

# Version Gates

Каждый major-релиз должен считаться готовым только после прохождения соответствующего набора проверок.

| Версия | Основной gate |
|---|---|
| **4.0.0** | Collaboration и коммуникации стабильны |
| **5.0.0** | Work OS покрывает основные рабочие процессы |
| **6.0.0** | Multi-organization, security и platform API готовы |
| **7.0.0** | Workspace + Projects + Automation + Ecosystem работают как единая платформа |

---

# Приоритеты

Приоритет разработки:

1. **Надёжность и безопасность**
2. **Коммуникации**
3. **Work OS**
4. **Синхронизация и offline**
5. **Администрирование**
6. **Интеграции**
7. **Автоматизация**

Новые функции не должны ломать существующие рабочие данные, E2E-чаты, расчёты, миграции или update flow.

- [ ] critical user flows протестированы;
- [ ] release notes подготовлены;
- [ ] rollback plan подготовлен.

## Целевая точка v7.0.0

**WorkerTink 7.0.0** должен представлять собой единое кроссплатформенное рабочее пространство, где коммуникации, люди, команды, смены, зарплата, документы, задачи, проекты, автоматизация и аналитика работают через общую систему identity, permissions, notifications, synchronization и integrations.

Версия 7.0.0 не должна требовать от пользователя понимания внутренней архитектуры WorkerTink: переход между Web, PWA и Desktop должен ощущаться как работа с одним и тем же продуктом.
