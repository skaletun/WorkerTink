# WorkerTink 2.19.0

**Рабочий календарь, деньги, люди и чаты — в одном приложении.**

WorkerTink — офлайн-first PWA для сменных сотрудников. Приложение помогает видеть рабочий ритм, считать выплаты и отпуск, общаться с коллегами и входить в аккаунт с нескольких устройств.

## Что внутри

### Рабочий центр
- графики 5/2, 4/1, 3/2, 3/1, 6/1, 2/2 и вахта 7/0;
- дневные и ночные смены, варианты 2/2 день/день, день/ночь, ночь/ночь;
- календарь смен на любой месяц;
- заметки по сменам и быстрые переходы к важным датам.

### Зарплата и отсутствия
- оклад, НДФЛ, аванс и остаток;
- отпускные и больничные с учётом стажа и среднего заработка;
- история доходов за 24 месяца;
- годовой обзор выплат.

### WorkerTink Community
- лента рабочих публикаций;
- реакции и комментарии;
- уведомления;
- поиск коллег и список контактов;
- отдельный раздел личных чатов.

### Личные сообщения
- E2E-шифрование содержимого на устройствах;
- текст, фото, видео и голосовые сообщения;
- ответы, редактирование и удаление сообщений;
- статусы отправки и прочтения;
- заметки смены можно отправлять в чат и применять обратно к календарю;
- медиа до 20 МБ с загрузкой частями и ленивой загрузкой.

### Безопасность и устройства
- отдельная серверная сессия для каждого телефона/ПК;
- просмотр активных сессий и отзыв отдельных входов;
- OnePass/WebAuthn с несколькими passkey на один аккаунт;
- QR-вход с телефона на ПК с отдельной сессией;
- рабочие данные остаются локально, каталог аккаунтов отделён от локального расчётного профиля.

## Архитектура

- React + TypeScript + Vite;
- Cloudflare Worker + D1 для каталога, социальных функций, сообщений и сессий;
- Service Worker + Cache API для offline-first режима;
- localStorage для локального рабочего профиля;
- Web Crypto API для E2E;
- WebAuthn / SimpleWebAuthn для OnePass.

## Запуск

```bash
npm install
npm run test
npm run build
npm run dev
```

## Directory API

```bash
npm --prefix directory-api install
cd directory-api
npx wrangler d1 migrations apply workertink-directory --local
npx wrangler d1 migrations apply workertink-directory --remote
cd ..
npm --prefix directory-api run deploy
```

## Важно для QR и OnePass

QR-сканер камеры требует HTTPS или localhost и разрешение камеры. В браузерах без `BarcodeDetector` доступен выбор фотографии QR или ручная обработка ссылки из QR.

Для OnePass каждый новый passkey регистрируется как отдельное устройство. Существующий passkey не удаляется при добавлении нового.

## Приватность

WorkerTink не отправляет рабочие расчёты на сервер. Серверный каталог нужен для WTinkID, социальных связей, сессий и доставки зашифрованных сообщений. Содержимое личного чата шифруется на устройстве до отправки.
