# WorkerTink 2.3.4

**WorkerTink** — локальный PWA для рабочего календаря, смен, зарплаты, отпусков, больничных и заметок по сменам.

Проект работает в браузере и на телефоне, устанавливается как PWA и может размещаться на **GitHub Pages**. Профиль пользователя хранится локально; backend для основной работы не нужен.

## Что есть в 2.3.4

### Рабочий календарь

- графики `5/2`, `4/1`, `3/2`, `3/1`, `6/1`, `2/2`, `7/0`;
- дневные и ночные смены;
- варианты `2/2`: День/День, День/Ночь, Ночь/Ночь;
- вахта 1–6 месяцев;
- праздничные дни;
- пользовательский коэффициент праздничной работы;
- ручное изменение отдельной смены;
- визуальная отметка изменённых смен;
- заметка прямо на конкретной дате.

### Зарплата

- оклад;
- НДФЛ;
- фактически отработанные смены;
- праздничная доплата;
- отпускные;
- больничные;
- история доходов за 24 месяца;
- итоговая сумма на руки;
- полноценный годовой итог по 12 месяцам;
- годовые суммы начислений, НДФЛ, дохода на руки, праздничных доплат, отпускных и больничных;
- годовая статистика по сменам, праздникам, отпуску и больничным;
- помесячная таблица с начислением, НДФЛ, авансом и остатком;
- ручная сумма аванса;
- автоматический расчёт остатка как `на руки − аванс`;
- отдельная дата зачисления аванса;
- отдельная дата зачисления остатка;
- даты выплат могут находиться в разных календарных месяцах.

**Авто-аванс в WorkerTink отсутствует.** Приложение не придумывает сумму аванса по проценту. Пользователь указывает фактически согласованную сумму, после чего WorkerTink показывает остаток.

### Отпуск и больничные

Периоды редактируются отдельно от настроек:

- добавить отпуск;
- удалить отпуск;
- добавить больничный;
- удалить больничный;
- увидеть использованные и оставшиеся дни отпуска;
- исключить дни отсутствия из обычной оплаты смен.

### Редактор смены и Markdown

Нажатие на любую дату календаря открывает редактор смены.

Можно:

- выбрать `День`, `Ночь` или `Выходной`;
- вернуть смену к графику;
- написать подробную заметку;
- использовать Markdown-разметку;
- открыть предпросмотр;
- экспортировать заметку конкретной смены в `.md`;
- экспортировать все заметки в один `.md`;
- импортировать WorkerTink `.md` обратно.

Markdown хранится **как исходный текст**, а не как HTML. Поэтому экспорт не теряет исходную разметку: `**жирный**`, `*курсив*`, заголовки, списки, цитаты, код и ссылки остаются в исходном виде.

Формат общего экспорта:

```md
# WorkerTink — заметки по сменам

## SHIFT: 2026-09-28 — День

# Отчёт

**Готово** и *важно*.

- пункт 1
- пункт 2
```

### Первый запуск

На чистом профиле WorkerTink открывает приветственный мастер настройки:

1. доход и НДФЛ;
2. график и дату начала;
3. подтверждение параметров.

Мастер можно открыть повторно из настроек.

## Local-first

WorkerTink не требует сервера для хранения профиля. Основные пользовательские данные остаются в `localStorage` браузера.

Экспорт JSON предназначен для резервной копии профиля. Markdown экспорт предназначен для переносимых заметок по сменам.

## Ограничения расчётов

WorkerTink является планировщиком и расчётным инструментом, а не бухгалтерской системой. Итоговая сумма может зависеть от условий работодателя, локальных актов, фактических начислений и действующего законодательства.

Праздничный коэффициент, НДФЛ и история доходов сделаны настраиваемыми, чтобы пользователь мог привести модель к своим условиям.

### Анимации интерфейса

WorkerTink 2.3.1 использует сдержанную motion-систему: стартовый экран загрузки, плавное появление вкладок, анимации модальных окон и toast-уведомлений. При включённом `prefers-reduced-motion` декоративные анимации отключаются.


## Вахта: День / Ночь / Сутки

Для графика **7/0** доступен отдельный выбор типа вахтовой смены: **День**, **Ночь** или **Сутки**. Выбор используется в мастере первоначальной настройки, настройках профиля, генерации календаря, редакторе отдельной смены и визуальной легенде. Тип «Сутки» хранится как отдельное значение `full` и не смешивается с дневной или ночной сменой. При переключении с 7/0 на другой график значение «Сутки» автоматически заменяется на «День».


## Годовой финансовый итог

Во вкладке **«Зарплата»** WorkerTink показывает отдельный годовой отчёт. Он не использует упрощённый прогноз: каждый из 12 месяцев пересчитывается тем же расчётным ядром, что и обычный месячный отчёт. Поэтому в годовой итог попадают:

- фактические смены и ручные изменения смен;
- праздничные смены и установленный коэффициент;
- отпуск и отпускные;
- больничные и выбранный процент оплаты по стажу;
- НДФЛ;
- ручной аванс и рассчитанный остаток.

Годовой блок показывает:

- **На руки за год** — сумма чистого дохода за 12 месяцев;
- **Начислено** — общий доход до НДФЛ;
- **НДФЛ** — суммарное удержание;
- **Среднее на руки** — годовой чистый доход / 12;
- базовую часть, праздничные доплаты, отпускные и больничные;
- количество смен, праздничных смен, дней отпуска и больничного;
- помесячную детализацию: начислено, НДФЛ, на руки, аванс и остаток.

Годовой итог считается **по месяцам начисления**, а не по фактической дате поступления денег на банковский счёт. Даты аванса и остатка используются как план выплат и не изменяют размер месячного начисления.

## Расчёт зарплаты с даты выхода

Зарплата начисляется только начиная с `startDate` — даты выхода на работу. Для месяцев до этой даты начисление равно нулю. В месяце выхода учитываются только дни графика начиная с даты выхода.

Стаж используется при расчёте больничных: до 5 лет — 60%, 5–8 лет — 80%, 8 лет и более — 100%.

## Аванс

Если для месяца не задана индивидуальная сумма аванса, WorkerTink использует значение по умолчанию, равное 50% указанного оклада. Пользователь может изменить сумму отдельно для любого месяца. Остаток рассчитывается как разница между суммой на руки и авансом.
